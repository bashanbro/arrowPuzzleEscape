# Arrows Puzzle Escape / 箭头逃脱谜题

**[English]** | [中文](#chinese)

## 🎮 Introduction
**Arrows Puzzle Escape** is an engaging puzzle game where your goal is to guide all the arrows out of the grid. Each arrow moves in its specific direction until it hits an obstacle or leaves the board. Strategic planning is key to solving the increasingly complex mazes!

> **Note:** This repository only contains the executable version of the game. The source code is not open to the public.

## ✨ Features
- **Challenging Puzzles**: Navigate through levels with increasing difficulty and complex grid layouts.
- **Strategic Gameplay**: Plan your moves carefully! Arrows can block each other.
- **Power-ups & Items**: Utilize various items to help you solve puzzles.
- **Customizable Experience**: Change themes, arrow shapes, and audio settings to your liking.

## 🎨 Themes & Customization
The game features 4 distinct visual themes and extensive customization options:

### Themes
- **Cyberpunk** (Default): A dark, neon-lit futuristic style.
- **Minimalist Light**: A clean, bright theme for a relaxed atmosphere.
- **Deep Ocean**: A soothing dark blue theme inspired by the sea.
- **Monochrome**: A high-contrast black and white theme.

### Settings
- **Arrow Shapes**: Choose from over 15 shapes including Circle, Star, Heart, Cat, Dog, Car, and more!
- **View Options**: Toggle Grid Lines and Grid Points for better visibility.
- **Audio**: Independently toggle Background Music (BGM) and Sound Effects (SFX).

## 🛠 Power-ups (Items)
Unlock and use items from the in-game shop to help you progress:
- **HINT**: Reveals a valid move.
- **TIME**: Adds 10 seconds to the timer.
- **FREEZE**: Pauses the timer for 10 seconds.
- **REVERSE**: Reverses an arrow's direction.
- **TELEPORT**: Teleports an arrow to an empty space.
- **COMPASS**: Shows the general escape direction.
- **AUTO**: Automatically moves a valid arrow.
- **CLEAR**: Forcefully clears a selected arrow path.
- **SHIELD**: Protects against one failure.
- **UNDO**: Reverts the last move.
- **BOMB**: Randomly destroys 3 arrows.

## 🚀 How to Play
1.  **Download**: download v.0.1.18.zip.
2.  **Run**: Navigate to the `v.0.1.18` folder and double-click `arrowPuzzleEscapeGUI.exe`.
3.  **Controls**:
    - **Left Click**: Launch an arrow.
    - **Right Click** (on arrow): Select/Deselect.
    - **Space**: Pause/Resume game.
    - **Menu Bar**: Access Themes, Settings, and Help.

## 📂 File Structure
- `dist/`: Contains the game executable (`arrowPuzzleEscape.exe`) and save data (`savegame.dat`).

## 🎮 游戏简介
**Arrows Puzzle Escape (箭头逃脱谜题)** 是一款引人入胜的益智游戏，你的目标是将所有箭头引导出网格。每个箭头都会沿着其指示的方向移动，直到遇到障碍物或离开棋盘。你需要精心策划每一步，解开越来越复杂的迷宫！

> **注意：** 本仓库仅包含游戏的可执行版本，源代码不公开。

## ✨ 游戏特色
- **极具挑战的谜题**：挑战不断增加的难度和复杂的网格布局。
- **策略性玩法**：仔细规划你的行动！箭头之间可能会互相阻挡。
- **丰富的道具**：利用各种道具来辅助解谜。
- **高度自定义**：随心切换主题、箭头形状和音频设置。

## 🎨 主题与自定义
游戏内置 4 种独特的视觉主题和丰富的自定义选项：

### 主题 (Themes)
- **赛博朋克 (Cyberpunk)**：默认主题，深色背景配以霓虹光效的未来风格。
- **极简白 (Minimalist Light)**：干净明亮的浅色主题，提供轻松的氛围。
- **深海 (Deep Ocean)**：深蓝色调，如同置身海底的宁静风格。
- **黑白 (Monochrome)**：高对比度的黑白风格，简洁纯粹。

### 游戏设置 (Settings)
- **箭头形状**：在设置面板中选择超过 15 种形状，包括圆形、星形、心形、猫咪、小狗、汽车等！
- **视图选项**：可开启/关闭网格线和网格点，辅助观察。
- **音频控制**：独立开关背景音乐 (BGM) 和音效 (SFX)。

## 🛠 道具说明
在游戏商店中解锁并使用道具来帮助通关：
- **提示 (HINT)**：推荐并演示一步可行的操作。
- **加时 (TIME)**：增加 10 秒游戏时间。
- **冻结 (FREEZE)**：暂停倒计时 10 秒。
- **反转 (REVERSE)**：反转选中箭头的方向。
- **传送 (TELEPORT)**：将箭头传送至空位。
- **指南针 (COMPASS)**：辅助显示建议的逃逸方向。
- **自动 (AUTO)**：自动执行一步最优移动。
- **消除 (CLEAR)**：强制清除选中的箭头路径。
- **护盾 (SHIELD)**：抵消一次失败判定。
- **改命 (UNDO)**：撤销上一步操作。
- **炸弹 (BOMB)**：随机摧毁 3 个箭头。
